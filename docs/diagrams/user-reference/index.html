Start small, verify the real runtime

Choose existing Hermes, Docker or Spot. Confirm one account and its regions, inspect coverage, then expand using the access review packet. Check scope and freshness before interpreting an empty board.

Compute is replaceable; S3/Iceberg preserves committed evidence and history. Keep one writer per namespace. Park compute without destroying the storage stack.
